# Самостоятельная работа по Bash-программированию

Репозиторий содержит решения задач по автоматизации и написанию скриптов в среде Bash.

## 📂 Структура файлов в проекте
*   `!README.md` — Описание лабораторной работы и инструкция по запуску.
*   `Bash.sh` — Интерактивное приветствие пользователя.
*   `calculator.sh` — Калькулятор суммы двух чисел.
*   `check.sh` — Анализатор чётности числа.
*   `counter.sh` — Счётчик строк в файле
*   `githubstatus.sh` — Продвинутый скрипт (для WSL) для цветного анализа репозиториев через GitHub API.
*   `password.sh` — Безопасный генератор случайных паролей длиной 8 символов.
*   `search.sh` — Скрипт для быстрого поиска файлов по расширению в текущей папке.
*   `structure.sh` — Создатель структуры веб-проекта

## 🚀 Инструкция по запуску
Все скрипты разработаны для запуска в терминале **Git-Bash** или **Ubuntu WSL**. В обычном PowerShell они работать не будут.

1. Откройте встроенный терминал Git-Bash в VS Code.
2. Перейдите в рабочую папку:
   ```bash
   cd TaskBash
   ```
3. Запустите любой интересующий скрипт через команду `sh`:
   ```bash
   sh calculator.sh
   ```
