## Основы Git

### Зачем Git?

#### Почему не флешка?

1. Флешка - потенциальный разносчик вирусов
1. Вашы личные данные могут попасть на чужой компьютер
1. Антивирус может удалить ваши файлы с флешки
1. Флешка может потеряться или сломаться

#### Почему не Yandex или Google диск?
1. Облако Yandex или Google не контролирует версии файлов
1. Ваши данные к Yandex или Google могут случайно остаться на чужом компьютере

### Преимущества Git

1. Трудно потерять свои проекты
1. Легко отслеживать версии ваших проектов
1. Легко делиться с другими людьми вашими проектами
1. Легко вести совместную работу над одним проектом
1. Git - де-факто стандарт и интегриитван почти во все современные технологии IT (например в VS code etc.)
1. Git можно создавать веб-страницы как на хостинге
1. Git-cервисы дают возможность автоматизировать собрки и тестировая ваших приложений

### Основные состояния Git-репозитория

1. **Инициализация** - `git status` - показывает текущее состояние репозитория
1. **Подготовка** - `git add .` - подготовка (добавление) изменений
1. **Фиксация** - `git commit -m 'Some message'`
1. **Cинхронизация** - удаленной копией текущего репозитория - `git push` и `git pull`

### Что можно сохранять в git?

1. Любые текстовые файлы, обьемом < ~ 40 mb.
1. Изображения, документы, mp3, PDF, короткие видео и т.п.
1. Все имена файлов и каталогов по-английски и без пробелов и спец.символов!

### Основные команды Git

Получить версию установленного Git:
``` shell
git version
```
или
```shell
git --version
```
Получить справку
```shell
git help
```
**Cменить текстовый редактор по умолчанию**
На `Micro` (проще для новичков)
```shell
git config --global core.editor "micro"
```
На `Nano` (чуть сложнее для новичков)
```shell
git config --global core.editor "nano"
```
На `VS code` (елементарен для новичков)
```shell
git config --global core.editor "code --wait"
```
**Важно представиться системе Git**
Сообщить свой никнейм
```shell
git config --global user.name "Fixic"
```
Сообщить свой эмэйл
```shell
git config --global user.name "my_email@mail.ru"
```
> **Если вы на чужом компьютере, то вместо --global используйте `--local`**

#### Клонирование репозитория

```shell
git clone https://github.com/Nikrolzz/Nikrolzz.git
```

открыть папку клонированного репозитория
```shell
cd folder_name
```
Получить статус текущего репозитория
```shell
git status
```
Получить состояние удаленного репозитория
```shell
git remote show origin
```
Получить локальные ветки текущего репозитория
```shell
git branch
```
Получить список удаленных веток
```shell
git remote --v
```
Получить общий лог
```shell
git log
```
Выйти из режима логов по клавише `Q`

Получить лог изменений
```shell
git log -p
```
Выйти из режима логов по клавише `Q`

Получить лог изменений с указанием кол-ва последних коммитов
```shell
git log -p
```
Выйти из режима логов по клавише `Q`

Получить хэши и их коммитов
```Shell
git log --oneline
```
После внесений изменений (модификаций) можно подготовить и закоммитить результат
```shell
git add .
```
и
```shell
git commit -m 'Any changes'
```
чтобы изменить текст последнего коммита
```shell
git commit --amend
```
