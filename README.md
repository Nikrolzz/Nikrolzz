# Описание проекта
Проект **SafeDrive** — это интеллектуальная информационная система, которая использует компьютерное зрение для контроля усталости водителя в режиме **реального времени**. Программа анализирует частоту моргания и положение головы, предотвращая аварии на дорогах.
